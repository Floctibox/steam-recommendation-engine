# Tests futurs

Aucun test métier n'est encore écrit. L'apprenant les construira après validation
des fonctions, des assertions et des cas limites, sur de petites données fictives.
Prévoir : jeux déjà possédés, utilisateur inconnu, données vides, ordre du classement,
absence de fuite de données. Ne pas dépendre du CSV complet pour les tests unitaires.
Un dossier de tests ne constitue pas une couverture de tests.
