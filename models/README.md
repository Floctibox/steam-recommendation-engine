# Modèles futurs

Aucun modèle entraîné actuellement. Les futurs artefacts seront ignorés par Git.
Lorsqu'un entraînement sera justifié, conserver avec chaque artefact : paramètres,
version des données, commit, environnement, graine éventuelle et métriques.
Ne pas introduire de registre de modèles ni d'outil MLOps avant d'en comprendre le besoin.
